# Login Feature

## Feature
User Login

## Description
The system allows registered users to log in using their username
and password.

## Requirements

REQ-LOGIN-001:
The user shall be able to enter a valid username.

REQ-LOGIN-002:
The user shall be able to enter a valid password.

REQ-LOGIN-003:
The system shall authenticate the user when valid credentials
are provided.

REQ-LOGIN-004:
The system shall display an appropriate error message when
invalid credentials are provided.

REQ-LOGIN-005:
The username field is mandatory.

REQ-LOGIN-006:
The password field is mandatory.

REQ-LOGIN-007:
The user shall be redirected to the dashboard after successful login.

REQ-LOGIN-008:
The password shall be masked while being entered.

REQ-LOGIN-009:
The system shall prevent login when the username or password
is empty.
