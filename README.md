# AI-Assisted Test Case Generator

## Objective

This project demonstrates how Generative AI can assist
software testers in analyzing requirements and generating
test scenarios, test cases, and test data.

## Technologies

- Generative AI / LLM
- Markdown
- Excel
- Manual Testing

## Workflow

Requirement
     ↓
AI Requirement Analysis
     ↓
Test Scenario Generation
     ↓
Test Case Generation
     ↓
Test Data Generation
     ↓
QA Review
     ↓
Traceability Matrix

## Features

- Requirement analysis
- Positive test generation
- Negative test generation
- Boundary/edge-case identification
- Test data generation
- Requirement traceability
- Ambiguity detection
